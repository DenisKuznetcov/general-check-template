# General check template preparation Google Apps Script
Цель скрипта: автоматизация настройки шаблона "Генпроверка".

## Описание
Алгоритм работы с файлом:
1. С листа "Генпроверка" предварительно удаляются данные с помощью соотв. кнопки на листе "Settings"
2. На лист "Генпроверка" добавляются требуемые данные, начиная со столбца А
3. Затем по нажатию на кнопку "Добавить столбцы генпроверки" на листе "Settings" запускается функция, 
добавляющая новые столбцы, настраивающая выпадающие списки, условное форматирование и формулы, используя данные с листа "Settings"
